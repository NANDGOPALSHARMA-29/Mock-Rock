# Mock & Rock 

AI-powered mock interview platform that helps users practice real-world interviews through personalized AI-generated questions, voice-based answers, and instant performance feedback.

## Features
- AI-generated interview questions
- Resume-based interview preparation
- Voice-based answers
- Speech-to-text
- AI answer evaluation & scoring
- Personalized feedback
